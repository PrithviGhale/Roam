# V0.4 dependency audit · 2026-10-06

This document records the original SDK 54 audit before the subsequent SDK 57 upgrade. Its dependency versions and counts describe that snapshot, not the current SDK 57 tree. The PostCSS override remains in place; the supported platform upgrade and its validation are documented in README. The SDK 57 installation reported **32 remaining findings** (10 moderate, 22 high, 0 critical); the upgrade is not a declaration that all advisories are resolved.

Baseline `npm audit`: **45** advisory package findings (19 moderate, 26 high, 0 critical). After the safe PostCSS override/install: **44** (19 moderate, 25 high, 0 critical). These are dependency-tree findings, not forty-four distinct remotely reachable app vulnerabilities. Counts can change as the advisory database changes.

## Applied fix

Root override pins **PostCSS 8.5.29**, within the existing major version, replacing 8.4.49 under Expo tooling. This fixes the reported CSS/source-map disclosure/XSS advisories. The lockfile was regenerated and `npm ci` verified the installed version. Expo SDK 54, React 19.1 and React Native 0.81.5 were retained. Worker type definitions were updated to the currently published version without changing runtime bindings. No `npm audit fix --force` or major platform upgrade was used.

The newly published Wrangler 4.148.0 was also inspected: its Miniflare 5.20261006.0-alpha still pins sharp 0.35.4, so that update does not resolve this advisory. The validated Wrangler version remains 4.147.0.

Low practical exposure is not a finding of “false positive.” None of the remaining findings is declared harmless. The Worker runtime code imports the Gemini SDK/Zod and built-in crypto, not Metro/Jest/sharp. Npm's root production classification includes mobile platform packages, so it cannot alone distinguish deployed Worker exposure. Before public release, review reachable deep-link/runtime paths and plan a supported Expo upgrade, with a fresh device/build regression pass.

Secrets: `.env`, `.dev.vars` and generated build artifacts stay ignored. The general REST key was removed from app configuration/native fallbacks. Public SDK keys need application/API restrictions. Prototype token protection is explicitly separated from future user identity verification and is still extractable from the app. Rate bindings are per Cloudflare location, not global hard spending limits; use upstream quotas too.
