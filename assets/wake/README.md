# Hey ROAM model

Generate **Hey ROAM**, English, **iOS**, Porcupine **4.x** in Picovoice Console.
Copy the downloaded model here as `hey-roam_ios.ppn` before building the iOS
development client. The Expo plugin copies it into the app's bundled resources.
Models are ignored by Git. Never put an AccessKey here or in app.config.
Enter the AccessKey on-device in development Diagnostics; it stays in SecureStore.
See `docs/v05-voice.md` for setup, license, privacy and device verification.
